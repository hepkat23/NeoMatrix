Install **NeoMatrix_v1.4.19.zip** in Calibre (Preferences → Plugins → Load plugin from file), then restart Calibre. The GitHub "Source code" archives are not the installer. Verify the download against `SHA256SUMS.txt` if you like.

Everything since 1.4.13:

- **1.4.19** — Send a Calibre position (for example one synced from KOReader) to an EPUB that BOOX has only opened to its cover, even without BOOX highlights. Uses NeoReader's document-root numbering, verified on a Go Color 7 Gen II against 210 native positions; unverified chapter layouts are refused and every result must round-trip to the exact CFI. Sync treats an image-only cover as the start of the book and offers the push instead of skipping it.
- **1.4.18** — BOOX cleanup backups save to `Documents/NeoMatrix backups` with a dated name. Fixes "Read-only file system" errors on macOS that stopped cleanup.
- **1.4.17** — Books already at the same position say "Already at the same position" instead of "The farthest Calibre position was retained".
- **1.4.16** — No match prompts for files that aren't books (TXT reading lists, notes, exports). "Leave unmatched" is remembered, including BOOX's duplicate copies, and the match dialog only lists books in the same format.
- **1.4.15** — The NeoMatrix window shows the real installed version.
- **1.4.14** — One pushed book you haven't reopened in NeoReader no longer stops the whole Sync; it is skipped and named in Sync details.

Tested on macOS with a BOOX Go Color 7 Gen II (Android 13). Other firmware may use different conventions; unverified cases are reported, not guessed. Keep your own backups.
